A

dsh-idle-crt — 待机显像管

v0.3.1 · MIT · 派生自 dsh-splash-crt

会话停了，人也不动键盘，页面才盖上一块 CRT：辉光字、扫描线、循环反色扫描。点一下、按个键，它就散了，页面还是原来那个页面。

系统屏保管不了「这一页」：Windows 的屏保是整机层面的，可 DSH 在跑长任务时你未必想让它盖掉进度。它只做一个很窄的判断——宿主给出 busy=false，并且这一页十分钟没人碰过。

p50 / p9916.7 ms / 16.7 ms
合成全 GPU
依赖空

B

dsh-om-messiah — 祷文转换

v1.4.3 · Host 插件 · 改写层三档

你发出去的每一句提示词，在交给模型之前先被改写成一篇万机之神祷文；回复原样返回。发祷文还是发原文，由你在发送前自己决定。

拦截点是 Host waterfall 的 agent/pre-step：拿到这一批用户消息，只替换本批次里的文本块，不碰历史消息，也不碰引擎自己追加的运行时上下文。

钩子agent/pre-step
档位framed · rules · off
旁路--serve

02

三条做法

写在代码里，不是写在简介里

  1. 01

    不魔改宿主

    插件只在边缘生长：DSH 的 cordis.patch.yml 加一行插入层，关掉就还原，宿主升级也不打架。主程序一行都不动，这是可安装的前提。

    宿主边界

  2. 02

    能上 GPU 就别上 CPU

    显像管把文字和提示各预渲染成一层纹理，逐帧只在片元着色器里合成。RTX 4060 上 p50 与 p99 都是 16.7 ms——一帧就是一个刷新周期。

    合成管线

  3. 03

    装完就能用

    一条 dsh plugin --profile desktop add <包名>，没有构建步骤，没有运行时依赖，装完刷新页面就活着。

    分发
