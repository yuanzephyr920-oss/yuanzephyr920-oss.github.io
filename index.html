dsh-idle-crt — 待机显像管

v0.3.1 · npm

会话停了，人也十分钟没碰鼠标键盘，页面才盖上一块 CRT：辉光字、扫描线、循环反色扫掠。点一下或按个键，它就散了。

  • 逐帧全 GPU 合成
  • 60 fps
  • 零运行时依赖

dsh-om-messiah — 祷文转换

v1.4.3 · npm

  • Host 插件
  • 发送前确认
  • 本地反代

02

三条做法

  1. 不魔改宿主。插件只在边缘生长——DSH 的 cordis.patch.yml 加一行插入层，关掉就还原，宿主升级也不会打架。
  2. 能上 GPU 就别上 CPU。显像管把文字和提示各预渲染成一层纹理，逐帧只在片元着色器里合成：RTX 4060 上 p50 与 p99 都是 16.7 ms。
  3. 装完就能用。一条 dsh plugin --profile desktop add <包名>，没有构建步骤，没有运行时依赖。
